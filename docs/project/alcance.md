# Alcance del proyecto

## Propósito

Construir una aplicación web mínima para registrar y consultar la asistencia de una empresa de 25 personas dedicada a la compra y venta de productos químicos.

## Incluido

- acceso mediante correo y contraseña;
- registro de una entrada y una salida por persona y fecha;
- creación, modificación y desactivación de usuarios;
- reporte de entradas posteriores a las 09:30;
- reporte de salidas anteriores a las 17:30;
- reporte de personas sin entrada ni salida en una fecha consultada;
- gráficos sencillos asociados a los reportes;
- API REST de lectura para empleados Activos, Inactivos o Todos;
- script de base de datos, pruebas, evidencias y presentación académica.

## Fuera de alcance

- dispositivos físicos, biometría o geolocalización;
- remuneraciones y gestión general de recursos humanos;
- aplicación móvil;
- recuperación de contraseña, verificación de correo o autenticación multifactor;
- turnos configurables, feriados y calendarios laborales avanzados;
- edición o auditoría avanzada de marcaciones;
- exportaciones, notificaciones y tiempo real;
- múltiples empresas, permisos configurables o paneles avanzados;
- infraestructura productiva, microservicios y despliegue en nube.

## Control de cambios

Una ampliación requiere una fuente oficial nueva o aprobación humana registrada en `docs/decisions/`. Una sugerencia de un agente nunca amplía el alcance por sí sola.
