# Alcance del proyecto

## Propósito

Construir un producto mínimo viable para el registro de asistencia de una empresa de 25 trabajadores y trabajadoras dedicada a la compra y venta de productos químicos.

## Alcance confirmado por el caso

El sistema solicitado es una aplicación web que deberá permitir:

- ingreso de usuarios mediante correo y contraseña;
- registro de entrada y salida;
- creación, modificación y eliminación de usuarios por un administrador;
- reporte de entradas posteriores a las 09:30;
- reporte de salidas anteriores a las 17:30;
- reporte de días sin registro de entrada ni salida;
- consulta mediante API REST de empleados filtrados por estado.

## Entregables académicos identificados

- producto mínimo viable operativo;
- código o scripts correspondientes a los requerimientos;
- script de creación de la base de datos;
- plan y evidencias de pruebas unitarias;
- presentación del proyecto;
- evidencias de las actividades 1.2 a 1.5;
- informe de empleabilidad y trabajo colaborativo.

## Pendiente de decisión

Los siguientes puntos aún no están aprobados y no deben asumirse durante la fase base:

- lenguaje y versión;
- framework de frontend o backend;
- motor de base de datos;
- arquitectura de software;
- estrategia de autenticación y autorización;
- formato de despliegue;
- herramientas de pruebas;
- diseño visual del producto;
- distribución de tareas y responsables.

## Fuera del alcance confirmado

Salvo que una fuente oficial o una decisión posterior indique lo contrario, no se consideran parte del MVP:

- integración con dispositivos físicos de marcación;
- procesamiento de remuneraciones;
- gestión completa de recursos humanos;
- aplicaciones móviles nativas;
- integraciones externas diferentes de la API solicitada;
- infraestructura productiva definitiva.
