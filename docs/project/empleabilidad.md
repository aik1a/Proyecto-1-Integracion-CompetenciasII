# Empleabilidad y trabajo colaborativo

Este entregable es académico y transversal; no agrega funciones al software.

## Contenido solicitado

- analizar un problema complicado relacionado con el trabajo;
- identificar al menos tres causas;
- proponer soluciones posibles;
- explicar tres beneficios de trabajar con metas de equipo;
- describir acciones de comunicación, coordinación y compromiso;
- presentar el trabajo con la estructura y evidencias solicitadas.

## Pendientes de fuente

La evaluación menciona los materiales `Orientaciones al Trabajo Colaborativo` y `Resolución de problemas`, pero no están entre las fuentes actuales. Deben incorporarse desde Aula Virtual si están disponibles.

Las pautas también combinan referencias a trabajo individual, roles y trabajo grupal. La modalidad y cantidad de integrantes deben confirmarse con el docente antes de completar esta entrega.

## Límite

No se crean ceremonias Scrum, métricas ni documentos empresariales para cumplir empleabilidad. Se prepara únicamente el informe o evidencia exigida por la evaluación.
