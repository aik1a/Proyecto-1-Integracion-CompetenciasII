# Sprints

Esta carpeta contendrá un directorio por sprint aprobado.

Ejemplo:

```text
docs/sprints/S01/
├── SPRINT.md
└── CIERRE.md
```

`SPRINT.md` se redacta y aprueba antes de crear `sprint/*`. `CIERRE.md` se completa antes de solicitar la integración a `main`.

No existe un sprint activo durante la fase base.
