# Sprint 01 — Base de datos

**Estado:** Pendiente

## Objetivo

Entregar el modelo relacional y un script MySQL reproducible para usuarios y asistencia.

## Fuentes y requerimientos

Pauta 1.3 y datos necesarios para CA-01, GU-01 a GU-03 y AP-01.

## Incluido

- modelo relacional mínimo;
- script de creación;
- restricciones necesarias;
- datos ficticios mínimos para demostración;
- conexión básica de la aplicación.

## Fuera de alcance

Pantallas, CRUD completo, reportes, gráficos, API y optimización avanzada.

## Criterios de aceptación

- el script crea la base desde cero;
- las relaciones permiten implementar los ocho requerimientos;
- los datos de prueba no contienen información real.

## Pruebas y evidencia

Ejecución limpia del script, inspección de tablas y una operación básica de conexión.

## Resultado

Se completa al cerrar la fase.
